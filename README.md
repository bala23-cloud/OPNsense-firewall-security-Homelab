## 📌 Project Overview

This project is a progressively built **network security laboratory** designed to understand how enterprise firewalls work from the ground up.

Instead of learning firewall configuration only through theory, every concept is implemented through a controlled lab environment using:

- Network configuration
- Firewall policies
- Traffic filtering
- Controlled attack simulations
- Packet analysis
- Firewall logs
- Troubleshooting
- Security monitoring
- Incident investigation

The lab will progressively evolve from a basic firewall into a **segmented security environment with DMZ, IDS/IPS, VPN, logging, and SOC integration**.

# 🎯 Objectives

- Understand firewall architecture and packet flow
- Build a virtualized OPNsense firewall
- Configure WAN, LAN, and DMZ networks
- Understand routing and default gateways
- Design network security zones
- Create and analyze firewall rules
- Understand rule ordering and rule matching
- Implement protocol and port-based filtering
- Understand stateful firewall behavior
- Analyze firewall logs
- Perform controlled security testing
- Implement DMZ isolation
- Configure NAT and port forwarding
- Explore IDS/IPS using Suricata
- Integrate firewall telemetry with Wazuh
- Develop SOC-oriented monitoring and investigation workflows
